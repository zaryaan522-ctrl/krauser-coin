# KRAUSER COIN ($KRAUS)

Experimental fictional memecoin landing page. No token, no transactions, no live data.

## Run locally
    npm install
    npm run dev        # http://localhost:5173

## Build
    npm run build && npm run preview

## Edit
- Telegram / X links: `LINKS` at the top of `src/App.jsx`
- Allocation and roadmap: `ALLOCATION` and `ROADMAP` in `src/App.jsx`
- Colours: CSS variables at the top of `src/styles.css`
